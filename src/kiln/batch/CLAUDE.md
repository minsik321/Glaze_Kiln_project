# kiln.batch — 06절 배치와 비중

기획서 전문: [`../../../docs/kiln-plan-v7.md`](../../../docs/kiln-plan-v7.md) 06절.
경계 계약: [`../../../docs/INTERFACES.md`](../../../docs/INTERFACES.md) `kiln.batch` 절.

이 문서는 부록 D의 고정 4항목 기재 방침을 따른다. 다루는 범위는 이 모듈
(`density.py`, `dip_time.py`) 단독이며, 두께 분포 계산(`kiln.thickness`)이나
위험 판정(`kiln.risk`)은 다른 모듈의 문서를 본다.

## ① 입력

- 비중 측정 이벤트(`DensityMeasurement`): 실측 비중 ρ [g/cm³], 교반 후
  경과 시간 [분] (6-3절 — 비중은 배치가 아니라 **측정 순간**에 귀속된다).
- 목표 두께 t_목표 [mm], 지금 통의 비중 ρ, 소지 흡수율, 흘러내림층 예상
  두께 t_flow [mm] (담금시간 역산 입력, 6-1절).
- 계수: k1(흡수층), g(ρ) 지수, m(ρ) 지수 — 값이 없으면
  `kiln.constants` 대장의 문헌 추정 초기값을 쓴다.

## ② 처리

- **g(ρ)·m(ρ) 정규화**: 둘 다 ρ=1.45에서 1.0이 되는 멱함수
  `(ρ/1.45)^exponent` 이며 단조증가다. 지수는 `constants.get("g_rho"|"m_rho").value`
  가 기본값이다(6-2절, 부록 C).
- **6-2절 경로 수정**: v5는 비중을 흡수층(t_abs)에만 넣었다. 물리적으로는
  고형분이 오르면 항복응력이 올라 흘러내리는 막 자체가 두꺼워지므로,
  흘러내림층(t_flow)에도 비중 항이 있어야 한다. `m_rho()` 가 그 보정이다
  — v5 본문의 "되직 → 흘러내림 위험" 서술과 수식을 맞췄다.
- **6-3절 재측정 권고**: `minutes_since_stirring > settling_limit_min`
  이면, 지금 판정이 OK여도 재측정을 권고한다.
- **6-4절 네 갈래 경고**: 정상 / 범위 초과(되직) / 범위 미달(묽음) /
  극단적 이탈(모델 적용 범위 밖). `blocks_progress` 는 **모든 갈래에서
  항상 False** — 경고가 떠도 진행을 막지 않는다.
- **6-1절 담금시간 역산**: `t_dip = [(t_목표 − t_flow) / (k1·흡수율·g(ρ))]²`.
  비중을 고정하고 담금시간 하나만 뒤집는다 — 미지수 둘(비중, 담금시간)에
  목표 하나면 해가 무수히 많기 때문이다. **도메인 가드**:
  `t_목표 ≤ t_flow` 면 괄호 안이 0 이하가 되어 제곱이 의미를 잃으므로,
  제곱하지 않고 `feasible=False` 와 사유를 반환한다.

## ③ 출력

- `DensityAdvice`: 상태, 안내 문구, `(문헌 추정 초기값 · 캘리브레이션 전)`
  주석, `blocks_progress=False` 고정, 재측정 권고 여부.
- `DipRecommendation`: 권장 담금시간 [s], 예상 평균 두께 [mm], 실행
  가능 여부, 불가 시 한국어 사유.

## ④ 차이

선행 대비 위치는 두께 계측 모듈에 종속되지만(부록 D 표), 이 모듈 단독으로
보면: 상용 유약 계산기·비중계 앱은 비중을 "맞다/틀리다"로만 판정하고
담금시간을 별도 입력으로 받는다. 본 모듈은 (a) 비중의 흘러내림 기여를
흡수 기여와 분리해 명시적으로 모델링하고, (b) 비중·담금시간 동시 역산이
불능(해가 무수)임을 코드 차원에서 못 박아 담금시간만 역산하도록
강제하며, (c) 경고를 진행 차단이 아니라 안내로 설계해 "개인 1인·가마
1대" 사용 범위(00절)에 맞춘다.

## 결합 효과

여기서 나온 `t_flow` 예측(비중 기여 포함)과 담금시간 권장값은
`kiln.thickness.profile.compute_profile` 의 입력이 된다. 비중 판정이
느슨하면(경고를 무시하고 진행) 두께 분포의 흡수층·흘러내림층 둘 다
어긋나고, 그 어긋남은 08절 위험 판정과 10절 계수 보정까지 그대로
전파된다 — 안쪽 루프(03절)가 통제되지 않으면 바깥 루프(조성 탐색)의
신호가 잡음이 되는 이유가 여기서 시작된다.
