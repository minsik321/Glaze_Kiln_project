# AICE 통합 방향성 플랜

## 1. 한 문장 정의

AICE는 원하는 유약 결과를 바탕으로 레시피를 탐색하고, 실제 제작 과정에서
추정한 도포 상태에 맞춰 소성곡선 후보를 보정하며, 가상 가마 제어와 소성 후
결과 피드백을 개인·공통 지식으로 축적하는 연구용 적응형 유약 소성 시스템이다.

> MVP는 결과를 보장하거나 실제 가마를 자동 운전하는 제품이 아니다. 모든 AI
> 출력과 소성곡선은 제한된 데이터에 근거한 실험적 추천이며 시뮬레이터에서
> 검증한다.

## 2. 전체 흐름

```text
Discover → Recommend → Measure → Visualize → Compensate
        → Simulate/Control → Observe → Learn → Share/Transfer
```

1. **Discover — 사례 선택**
   - 사진, 색상, 광택, 질감, 투명도와 소성조건으로 기존 레시피를 탐색한다.
   - 결과 사진과 데이터 출처, 실제/합성 여부 및 사용 조건을 함께 표시한다.

2. **Recommend — AI 레시피 추천**
   - 적합한 사례가 없으면 목표 색상과 표면 특성에 가까운 후보를 추천한다.
   - 우선 기존 레시피 검색·랭킹으로 구현하고, 새 배합 생성은 데이터와 안전
     제약이 확보된 범위에서만 수행한다.
   - 사진은 예상 결과를 이해하기 위한 유사 사례로 제시하며 동일 결과를
     보장하는 미리보기로 표현하지 않는다.

3. **Measure — 도포 상태 추정**
   - 입력: 유약 비중, 담금 전후 무게, 담금시간, 시유 방법, 기물 형상·면적,
     소지와 초벌 조건.
   - 출력: 도포 증가량, 평균 추정 두께, 상대 도포지수, 목표 대비 편차와
     신뢰도.
   - 전후 무게만으로 실제 두께를 직접 측정할 수는 없다. 면적과 건조밀도 또는
     실험 보정값이 없으면 결과를 `상대 도포지수` 또는 `가정 기반 추정 두께`로
     표시한다.

4. **Visualize — 기물별 도포 시각화**
   - 기물 모형을 확대해 평균 및 위치별 추정 두께를 색상 맵으로 표시한다.
   - 총 무게만 있는 경우 위치별 mm를 실측값처럼 표시하지 않는다. 형상 기반
     분포 모델, 구간별 측정 또는 영상·스캔 데이터가 있을 때만 위치별 값을
     제공하고 근거와 오차범위를 표시한다.
   - 과도포·부족도포·편차가 크면 재도포, 제거, 건조 확인 또는 진행 여부를
     선택지와 위험 근거로 제시한다.

5. **Compensate — 두께 기반 소성곡선 보상**
   - 입력: 레시피, 소지, 도포 상태, 기준 소성곡선, 가마 프로필과 적재 조건.
   - 제한 범위에서 승온률, 최고온도, 유지시간과 냉각구간 후보를 생성한다.
   - 목표 특성 오차, 결함 위험, 소성시간·에너지 및 기준곡선 변경량을 비교해
     상위 후보와 선택 이유를 제공한다.
   - 초기 MVP는 규칙 기반 대리모델과 제한된 탐색을 사용한다. 관측 데이터가
     충분히 쌓인 범위부터 검증된 예측 모델로 교체한다.

6. **Simulate/Control — 가상 가마와 이중 제어**
   - 선택한 소성곡선을 가상 가마에 전달하고 목표온도, 센서온도, 기물 추정온도,
     열일, 히터 출력과 추종오차를 기록한다.
   - MVP의 이중 제어는 `외측 열일/곡선 보정 루프 + 내측 온도 추종 루프`로
     정의한다. 다른 직렬 PID 구조를 사용할 경우 제어 대상과 블록 구조를 먼저
     별도 확정한다.
   - 출력 제한, anti-windup, 센서 이상, 과열 및 추종 실패 경보를 포함한다.

7. **Observe — 결과 촬영과 비교**
   - 표준 조명·배경·거리와 색상 기준표를 사용해 결과 사진을 촬영한다.
   - 사용자가 목표 대비 색, 광택, 질감, 투명도와 결함을 평가한다.
   - 레시피·도포·기물·가마·설정곡선·실제곡선·사진을 하나의 실행 기록으로
     저장한다.

8. **Learn — 공통 및 개인 적응**
   - 개인 차이는 우선 개인 기록 검색, 가마별 보정계수와 개인 사후분포로
     반영한다. MVP에서 사용자별 모델을 매번 재학습하지 않는다.
   - 여러 사용자에게 같은 방향의 잔차가 반복될 때만 공통 모델 개선 후보로
     올린다. 자동 반영하지 않고 데이터 품질검사, 동의, 최소 표본 수, 검증,
     모델 버전 관리와 롤백을 거친다.
   - 사진 검색용 RAG와 수치 예측 모델의 학습은 구분한다. RAG는 유사 사례를
     찾는 수단이며 그 자체가 모델 가중치 학습은 아니다.

9. **Share/Transfer — 공유 및 내 조건에 적용**
   - 사용자가 동의한 실행만 익명화해 공유한다.
   - 공유 기록에는 레시피뿐 아니라 소지, 도포 상태, 기물 형상, 가마 프로필,
     적재, 실제 온도곡선, 사진과 출처를 포함한다.
   - 다른 사용자의 곡선을 그대로 복사하지 않고 내 가마의 열용량·열손실·출력과
     기물 조건으로 변환한 후보를 시뮬레이션한 뒤 적용한다.

## 3. 공통 실행 데이터

`AiceRun` 하나에 다음을 저장한다.

- 목표 특성과 선택·추천 레시피, 유사 결과 사진
- 비중·무게·담금시간 등 원시 측정값과 단위
- 평균/위치별 도포 추정값, 계산 방식, 보정계수와 불확실성
- 기준곡선, 후보곡선, 목적함수·제약조건, 선택 이유
- 가마·기물·소지·적재 프로필과 제어 파라미터
- 목표/실제 온도, 열일, 출력, 추종오차와 경보
- 소성 후 표준화 사진, 사용자 평가와 결함 라벨
- 실제·합성·규칙 기반 구분, 데이터·모델 버전, 출처·권리·동의 이력

## 4. MVP 범위와 순서

### P0 — 데이터 계약과 안전 경계

- `AiceRun` 스키마와 데이터 출처·동의·버전 규칙 확정
- 실제 두께, 추정 두께, 상대 지수의 UI 표기 분리
- 이중 제어 구조와 소성곡선 안전 제약 확정

### P1 — 현재 코어 연결

- 기존 레시피/조성 후보 → 도포 추정 → 규칙 기반 위험 평가
- 두께 편차에 반응하는 복수 곡선 후보 및 점수 비교
- 선택 곡선을 가상 가마 목표로 자동 전달
- 입력 하나를 바꾸면 이후 결과가 모두 바뀌는 통합 테스트

### P2 — 결과 기록과 개인화

- 표준화 사진 촬영·저장과 목표 대비 평가
- 개인 가마·소지·레시피별 보정계수 및 유사 과거 기록 검색
- 공유 기록을 내 가마 조건으로 변환하고 시뮬레이션

### P3 — 데이터 기반 AI

- 사용 허가가 명확한 레시피·사진 데이터셋 구축
- 목표 특성 기반 검색·랭킹과 범위 밖 입력 경고
- 실제 관측 데이터로 결과·결함 baseline 모델 평가
- 검증을 통과한 출력만 곡선 후보 평가에 사용

### P4 — 실제 가마 확장

- 실제 센서·컨트롤러 연결은 별도 안전 검증 후 수행
- 사용자 승인, 독립 과열 차단, 통신 실패 시 안전상태와 감사 로그 필수

## 5. 성공 기준

- 하나의 입력 변경이 도포 추정, 위험, 후보 곡선과 시뮬레이션에 전파된다.
- 모든 수치에 실측·추정·합성 여부와 신뢰도를 확인할 수 있다.
- 동일 입력과 모델 버전으로 결과를 재현할 수 있다.
- 개인 보정과 공통 모델 갱신이 분리되고 이전 버전으로 되돌릴 수 있다.
- 공유 데이터가 권리·동의 조건을 지키며 다른 가마에 그대로 복사되지 않는다.
- 실제 품질 보장이나 검증되지 않은 최적성을 주장하지 않는다.

## 6. 특허·문헌 기반 MVP의 가능 범위

공개특허만으로 실제 정확도, 일반화 성능 또는 품질 개선을 입증할 수는 없지만,
다음 수준의 연결성 검증 MVP를 만드는 데에는 충분하다.

- 목표 색상과 특성에 따른 소규모 레시피 검색·추천
- 특허 실시예와 문헌 범위를 이용한 초기 규칙·제약조건 구성
- 비중·무게·면적·밀도 가정에 따른 도포 두께 추정
- 가상의 위치별 두께 분포와 위험도 시각화
- 두께 편차에 반응하는 소성곡선 후보 생성과 점수 비교
- 합성 시나리오를 이용한 곡선 최적화
- 선택 곡선의 가상 가마 및 이중 제어기 전달
- 소성 결과 평가에 따른 다음 곡선과 개인 가마 보정계수 갱신
- 전 과정을 하나의 `AiceRun`으로 저장·공유하는 데모

이 MVP의 AI는 `특허·문헌 기반 규칙 + 제한된 특허 실시예 + 합성 데이터`로
구성한다. 이를 실제 관측 데이터로 표현하지 않으며, 실제 정확도와 일반화를
주장하지 않는다.

## 7. 활용할 공개특허와 적용 범위

### 7.1 목표 색상 기반 유약 레시피·색상 예측

- 문헌: [TW202533100A / TWI857914B](https://patents.google.com/patent/TW202533100A/en)
- 공개 내용: 레시피와 색상 데이터셋, 목표 색상, AI 예측색, 색상 차이 비교,
  임계값을 이용한 레시피 재탐색.
- AICE 활용:
  - 목표 색상에 가까운 기존 레시피 검색·랭킹 구조
  - 목표색과 예상색의 차이 표시
  - 레시피 후보와 유사 결과 사진을 함께 보여주는 UI
- 한계: 공개문헌은 재사용 가능한 대규모 학습 데이터셋을 제공하지 않는다.
  MVP는 자체 소규모 표와 합성 샘플을 사용하며 `patent-derived/synthetic`으로
  표시한다.
- 권리 참고: 공개 페이지상 대만 등록과 대만 패밀리가 확인된다. 실제 권리범위와
  국가별 상태는 변리사가 공식 등록부와 청구항을 다시 확인한다.

### 7.2 결과 피드백 기반 소성곡선 최적화와 PID 전달

- 문헌: [CN108931144A](https://patents.google.com/patent/CN108931144A/zh)
- 공개 내용: PID 온도곡선 추종, 실제 온도 시점 기록, 작업자 결과 점수,
  회귀식, 유전 알고리즘 곡선 최적화, 다음 소성 제어기로의 곡선 전달.
- AICE 활용:
  - 가상 소성 결과를 학습 샘플 형태로 저장
  - 복수 후보곡선의 목적함수 평가 및 선택
  - 선택 곡선을 가상 가마 제어기에 자동 전달
  - 결과 평가가 다음 실행에 반영되는 피드백 데모
- AICE 확장:
  - 결과 총점 하나가 아니라 색·광택·질감·투명도·결함·시간·에너지를 분리
  - 소성 전 추정 두께, 레시피, 소지, 적재와 가마 프로필을 입력에 추가
  - 공통 보정과 개인 가마 보정을 분리
- 한계: 실제 온도·결과 표본은 제공되지 않으므로 MVP에서는 합성 실행 기록을
  사용한다.
- 권리 참고: 공개 페이지상 중국 출원만 확인된다. 표시된 법적 상태는 참고값이며
  공식적인 실시 가능성 판단은 아니다.

### 7.3 유약층 두께와 소성 후 색·표면 결과의 관계

- 문헌: [US20240360039A1](https://patents.google.com/patent/US20240360039A1/en)
- 공개 내용: 이중 유약층의 조성·입도·두께, 소성 조건, 두께별 색차와 표면
  거칠기 실시예.
- AICE 활용:
  - 유약층 두께가 결과 색과 표면에 영향을 줄 수 있다는 근거
  - 특정 조건에 한정된 두께 민감도 데모 시나리오
  - 두께별 위험·결과 점수의 초기 방향성 설정
- 한계: 위생도기와 특정 이중 유약 조건의 사례이므로 다른 유약에 일반화하지
  않는다. 이 문헌만으로 두께별 소성곡선 변경량을 산출하지 않는다.
- 권리 참고: 공개 페이지상 미국·유럽 출원은 계속 중인 것으로 표시된다. 현재
  청구항의 중심은 특정 위생도기와 유약층 구성이고, 범용 AI 소성곡선 보정은
  아니다.

### 7.4 도포 전후 측정에 의한 유약층 두께 제어

- 문헌: [DE3320160C2](https://patents.google.com/patent/DE3320160C2/en)
- 공개 내용: 도포 전후 광학 측정값의 차이로 층 두께를 구하고, 목표 두께와의
  편차를 도포 장치에 되먹임하는 구조.
- AICE 활용:
  - 도포 전후 상태 차이를 이용한 두께 관리라는 선행 개념 인용
  - 목표 두께 대비 편차 계산과 시각화 구조 참고
- AICE 차이:
  - 광학 산업장비가 아니라 비중·전후 무게·기물 면적·건조밀도와 보정계수를
    사용해 평균 두께를 추정
  - 도포장치를 제어하는 대신 두께 편차를 소성곡선 후보에 전달
- 한계: 이 특허는 AICE의 무게 기반 계산식을 직접 뒷받침하지 않는다.
- 권리 참고: 공개 정보상 권리는 만료된 것으로 표시되지만 공식 상태는 변리사가
  다시 확인한다.

### 7.5 비특허 참고자료

외부 레시피·사진은 각 출처의 라이선스와 제공 조건이 확인된 범위에서만 사용한다.
특허의 사진·도면을 학습 데이터나 앱 자산으로 그대로 복제하지 않고, 공개된
수치·관계·방법을 구조화해 자체 도표와 합성 시나리오를 생성한다.

## 8. AICE가 검토할 특허 방향

개별 AI, 두께 계산, 최적화, PID 또는 기록 기능 자체가 아니라 다음의 결합과
실제 데이터 전달 관계를 중심으로 검토한다.

> 소성 전에 계량값과 기물 조건으로 유약 도포 상태와 불확실성을 추정하고,
> 이를 레시피·소지·가마 프로필과 결합해 제약된 소성곡선 후보로 변환·평가한
> 뒤 선택 곡선을 이중 제어기에 전달하며, 표준화된 결과 관측의 공통 잔차와
> 개인 잔차를 분리해 다음 레시피 추천·곡선 변환·가마 보정계수를 갱신하는
> 적응형 시스템.

특허 검토용 핵심 연결은 다음과 같다.

```text
목표 색상·표면 특성
→ 레시피 및 유사 결과 후보
→ 도포 전후 계량값
→ 두께 분포·불확실성
→ 두께 조건부 소성곡선 후보
→ 제약·위험·시간·에너지 평가
→ 이중 제어기와 가상 가마
→ 실제곡선·결과 사진·사용자 평가
→ 공통 모델 오차 / 개인 오차 분리
→ 다음 추천과 개인 가마 보정
```

차별화는 화면을 순서대로 배치한 것만으로 성립하지 않는다. 실시예에서 다음을
코드와 로그로 입증한다.

- 추정 두께를 바꾸면 후보 소성곡선과 위험 점수가 달라진다.
- 가마 프로필을 바꾸면 같은 후보도 다른 제어곡선과 출력으로 변환된다.
- 결과 평가를 바꾸면 다음 실행의 공통 또는 개인 보정값이 달라진다.
- 모든 변경에 입력, 계산 방식, 근거 출처, 모델 버전과 선택 이유가 남는다.

현재의 제한적 조사에서는 이 연결 전체와 정확히 같은 단일 문헌을 확인하지
못했다. 그러나 복수 선행문헌의 결합으로 쉽게 도출되는지까지 검토해야 하므로,
신규성·진보성과 청구항 범위는 변리사의 전문 선행기술 조사로 확정한다.

## 9. 특허 기반 데이터 사용 규칙

특허에서 얻은 값과 AICE가 만든 값을 다음처럼 구분한다.

| `source_type` | 의미 |
|---|---|
| `patent_example` | 특허 실시예에 직접 기재된 측정값 |
| `patent_range` | 특허에 기재된 범위·조건 |
| `literature` | 논문·기술문헌의 관측값 |
| `inferred` | 공개내용에서 AICE가 해석·변환한 값 |
| `synthetic` | 규칙 또는 시뮬레이터가 생성한 값 |
| `observed` | 자체 실험에서 직접 측정한 값 |

각 레코드에는 공보번호, 청구항·문단·실시예 위치, 원래 조건, 단위변환, AICE
적용 방식, 가정과 신뢰도를 함께 저장한다. `patent_example`, `inferred`,
`synthetic`은 실제 관측 정확도의 근거로 사용하지 않는다.

AI는 다음 층으로 분리한다.

1. **Patent/Literature RAG:** 출처가 있는 규칙·사례 검색
2. **Rule/Simulation Model:** 제약조건과 합성 시나리오 생성
3. **Experimental Predictor:** 위 데이터로 동작 흐름을 보여주는 MVP 모델
4. **Personal Calibration:** 사용자별 가마·소지·작업 편차 보정

화면에는 `특허 실시예 기반`, `AICE 추론`, `합성 시뮬레이션`, `자체 관측`을
명확히 표시한다.

## 10. 인용·권리 관리 원칙

- 연구·교육 목적에 필요한 범위만 인용하고 공보번호와 원문 링크를 표시한다.
- 특허 설명과 AICE의 해석·합성 가정을 문장과 데이터 모두에서 분리한다.
- 원문·도면·사진을 대량 복제하지 않고 필요한 사실과 방법을 요약·구조화한다.
- 비상업 연구용 MVP와 실제 서비스 배포·판매를 구분한다.
- 연구·시험 예외나 출처 표시는 상용 실시 허락을 의미하지 않는다.
- 외부 공개·실제 가마 연결·상용화 전에는 국가별 특허 패밀리, 법적 상태와
  청구항을 기준으로 실시자유를 다시 검토한다.
- AICE의 구체적인 보상식과 피드백 구조는 공개 발표 전에 출원 순서를 변리사와
  확인한다.

자료 확인일: 2026-09-16. 공개 페이지의 법적 상태 표시는 참고용이다. 이 문서는
연구용 MVP와 기술 방향 정리를 위한 것이며 법률 의견이나 특허 등록·실시 가능성
판단을 대신하지 않는다.
