# 되살리면 안 되는 설계

기획서 [부록 E](kiln-plan-v7.md)의 문제–해결 대장을 코드 관점으로 옮긴 것.
v7은 v5의 오류를 고친 개정본이다. **여기 적힌 것들은 "단순화"처럼 보이지만
전부 한 번씩 틀렸던 설계다.** 리팩터링 중 무심코 되살리기 쉬우므로 남긴다.

---

## 폐기 — 다시 쓰면 안 되는 것

### Dry–Matte–Clear 삼각좌표 → 광택도 × 투명도 2축 (4-1)

셋은 배타적 성분이 아니라 용융도가 올라가는 한 축 위의 순서다. 표면은 한
상태만 가지므로 "Dry 60 / Matte 30 / Clear 10"이 정의되지 않는다. 더 결정적으로
**소성 결과를 그 척도로 매기는 방법이 없다.** 목표와 결과가 같은 척도 위에
있어야 되먹임이 성립한다.

### `e_H = (H_목표 − H_실제) / H_목표` → `Δt_eq` (9-5)

H는 거의 전부 최상단에서 쌓인다. 100℃/h·1220℃ 소성에서 3시간 시점의 H_목표는
`5.6e-14` 다. **소성 앞 80% 구간에서 0으로 나눈다.** 상대오차의 분모로 쓸 수 없다.
대신 감시/능동 2모드로 나누고, 능동 모드에서
`Δt_eq = (H_목표 − H_실제)/exp(−E/R·T_peak)` 를 **초 단위**로 낸다.

### 냉각을 H에 합산 → H_s와 냉각 프로파일 분리 (9-4, 10-3)

H는 급냉과 서냉을 구분하지 못한다.

```
급냉(310℃/h) + 1220℃ 유지 49분   H = 7801
서냉(77.5℃/h) + 1220℃ 유지 15분  H = 7801   ← 동일, 질감은 정반대
```

결정 석출은 특정 온도대의 **체류 시간**이 결정한다. 냉각은 온도–시간 곡선
그대로 다루고 H로 환산하지 않는다.

### "온도는 가마 의존, 열일은 독립" 대비축 (10-3)

E가 주어지면 `dH/dτ = exp(−E/RT)` 이므로 H(t)와 T(t)는 **일대일 변환**이다.
정보량이 같으므로 한쪽이 가마 의존이고 다른 쪽이 독립일 수 없다.
실제 구분은 **설정 스케줄 vs 달성 열이력**이다.

### 콘 슬라이더로 Stull 경계 연속 이동 → 이산 프리셋 (4-3)

이동량을 산출할 함수가 없다. `cone6` / `cone11` 프리셋만 두고 각각의 출처를
병기한다.

### SiO₂:Al₂O₃ 비 1차원 판정 → (SiO₂, Al₂O₃) 2차원 영역 (4-3, 5-2)

비 하나로 축약하면 **석회석 축이 판정에서 사라진다.** 석회석 10%p 하나가
조성 후보 전체 폭의 6~13배를 움직이는데도 비는 거의 반응하지 않는다.

### 승온 응답 역산으로 적재량 검증 → 총량 이상 감지 (9-2)

10kg 등록 vs 12kg 실제의 신호 차는 **2.7%** 인데 계통 불확실은 ±10% 다
(공급전압 ±5% → 전력 ±10%, 열선 노후 −5~15%). **신호가 계통 불확실보다 작다.**
기능 목표를 gross error detection으로 낮추고 임계를 계통 불확실보다 크게 잡는다.
"적재 오등록 판별"은 주장하지 않는다.

### 소성 조건에 베이지안 최적화 (5-3)

소성 조건은 **회차당 1점만** 관측된다. 3차원 공간에 20점은 BO가 작동할 밀도가
아니다. BO·Active Learning·GP는 **조성 계층에 한정**한다. 소성 조건은
순차 1변수, 사전 지식 기반.

### 재시유 예측에 `✓ 안전` 확정 기호 (8-4)

07절이 "국소 최대 두께가 가장 불확실"이라고 못 박았고 스케줄 보정에는
"효과 불확실"을 붙여놓은 것과 태도가 어긋난다. **어떤 선택지에도 확정 기호를
붙이지 않는다.** 재시유는 오히려 재습윤으로 모델 적용 범위를 벗어난다.

## 되돌리기 쉬운 미묘한 것

### 평균 두께는 "항상 실측과 일치한다" (7-2)

**동어반복이자 거짓이었다.** 평균 = 총부피/총면적이고 제약을 그렇게 걸었으니
당연히 일치한다 — 모델이 맞힌 게 아니라 나눗셈이다. 그리고 실제 계산되는 값은
`W/(A·ρ_dry)` 인데 v5에는 ρ_dry가 아예 없었다.

```
W=96g, A=0.060 m²
  ρ_dry=1.3 → 1.23mm   1.5 → 1.07mm   1.7 → 0.94mm
  1.6으로 가정했는데 실제 1.35면 19% 과소평가
```

08절 안전 범위가 0.8–1.3mm다. **ρ_dry 하나로 안전창이 한 칸 통째로 이동한다.**

총량 제약이 보장하는 것은 "모델이 분포를 어떻게 그리든 총량은 일치한다"는
**내적 정합성**이지 실측과의 일치가 아니다.

| | 정확도 의존 |
|---|---|
| 평균 두께 | ρ_dry · A 에 의존 (k₂에는 무관) |
| 위치별 분포 | k₂ 에 의존 |
| 국소 최대 두께 | k₂ 에 의존 — **가장 불확실하며 흘러내림 판정의 근거** |

### t_flow에 비중 항이 없었다 (6-2)

v5 본문은 "되직 → 두껍게 붙어 흘러내림 위험"이라고 서술해놓고 수식은 비중을
흡수층에만 넣었다. **물리적으로는 반대다** — 고형분이 오르면 항복응력이 급격히
올라 흘러내리는 막이 두꺼워진다. `m(ρ)` 가 그 수정이다.

### 예측(생두께)과 파단면(소성후) 단위 불일치 (7-4)

그대로 빼서 오차로 쓰면 계수가 **반대 방향으로 수렴한다.**
`오차 = (t_예측 · s) − t_파단면실측`, s < 1.

### 편차비 사후 진단이 자기 입력을 되돌려준다 (7-7)

편차비 = `1 + k₂·m(ρ)/t_abs` 이고 t_abs는 사용자가 입력한 비중의 함수다.
예측 편차비로 진단하면 결론은 "당신이 낮은 비중을 입력했습니다"뿐이다.
**파단면 실측이 있는 회차에만 활성화한다.**

### H(t)의 T가 무엇인지 쓰지 않았다 (9-3)

센서 온도라면 9-1절 ①이 스스로 부정한 값이고, 기물 온도라면 실물에서 관측
불가다. 시뮬레이터에서는 노드 온도가 다 있으니 돌아가지만 그건 관측 문제를
회피한 것이다. **센서 기준 H_s로 못 박고**, 기물–센서 오프셋을 캘리브레이션
대상으로 둔다. "기물이 받은 열을 직접 제어한다"고 주장하지 않는다.

### 검증이 자기 생성기 역추적 (12-2)

**생성기와 추정 모델이 같으면 어떤 수렴도 자명하다.** v5의 "더미 20회차 수렴"이
그랬다. 시뮬레이터의 생성기는 추정 모델과 **구조적으로 다르게(오지정)** 만들고
외란을 주입한다. 결과는 "수렴"이 아니라 "RMSE X% 감소, Y% 편향 잔존"으로 적는다.

삭제된 검증 항목:
- "k₂ ±50% 스윕에도 평균 두께 보존" — 총량 제약을 걸고 총량을 확인하는 산수
- "α·β 부호 유지" — 단조감소 함수의 단조성 확인

### 목표별로 축적 데이터 저장 (5-5)

사용자가 목표를 바꿀 때마다 리셋된다. **조성→결과 매핑**으로 저장한다.

### 초벌 온도를 "캘리브레이션으로 흡수" (7-5)

흡수율은 k₁과 곱으로만 식별되므로 거기에 밀어 넣으면 **k₁이 조용히 틀어진다.**
초벌 온도 변경은 **재캘리브레이션 트리거**다.

### 왁싱을 무시 (7-5)

왁스 무게는 시유 전 무게에 포함되고 왁스 부위 면적은 A에서 제외된다.
미처리 시 **총량 앵커가 깨진다.**

### 착색 산화물 참고 색상표를 조성 예측으로 확장 (4-4-a)

6종 착색 산화물 참고 색상표(문헌값 열람 + 보간)는 04절 예외로 명시됐지만,
그 경계를 조성 탐색(05절)이나 목적함수(5-4절 d)로 **넓히면 00절이 다시
깨진다.** 지켜야 하는 경계 셋:

- 참고 색상은 `kiln.search` 의 입력이 아니다 — 원료 5종에 착색 산화물을
  추가하거나, 후보 생성이 색상표를 참조하게 만들지 않는다.
- 참고 색상은 5-4절 거리 d에 들어가지 않는다 — "이 색에 가까운 후보"를
  점수화하지 않는다. 04-1절 목표 축은 광택도 × 투명도 2축으로 고정이다.
- 화면에 낼 때 문헌 참고값 캐비어트(4-4-a)를 **떨어뜨리지 않는다** — Stull
  참조(4-3절)와 같은 이유다.

산화·환원 분위기별, 첨가 농도별로 색상값을 늘리는 것도 다시 쓰면 안 된다
(예: 크롬의 핑크 발색은 극소량 + 주석 함유 조건에서만 나온다) — 실측 데이터
없이 표를 늘리는 것은 00절이 막는 "조성으로 결과를 예측한다"의 다른 얼굴이다.

## 고칠 수 없다고 인정한 것 (부록 A · E)

리팩터링으로 해결하려 들지 말 것. 이것들은 실측 없이는 닫히지 않는다.

| 항목 | 왜 못 고치는가 |
|---|---|
| E, ρ_dry의 값 | 실측 없이 확정 불가. 파라미터 노출 + 민감도 보고만 |
| k₂ / s 분리 | 같은 신호(파단면 두께)에만 영향 → 분리 동정 불가 |
| k₁ / 흡수율 분리 | 곱으로만 식별됨 |
| 국소 최대 두께 신뢰도 | k₂ 의존, k₂는 **인출 속도**에 지배되는데 인출 속도는 기록되지 않는다. 상수가 아니라 **분산을 가진 양**이며 데이터로 줄일 수 없다 |
| 기물 온도 관측 | 센서 기준 재정의 외에 방법 없음 |
| 저실리카 매트 vs 미용융 | Stull 좌표상 같은 방향. 차트만으로 판별 불가. 갈라주는 것은 콘·유지시간·냉각이다 |
| 기포형/흘러내림형 사전 판별 | 유약 용융 범위와 소지 가스 방출 온도대는 관측 대상이 아니다. 초기에는 양쪽 표시 |
| 실제 품질 개선 | 실물 소성이 없다 |
